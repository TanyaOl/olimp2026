📘 Як розв’язувати олімпіадну задачу

  1. Прочитай умову двічі і виділи: що дано, що знайти, які обмеження.
  2. Розбери приклади вручну — це перевірка, що ти зрозумів(ла) умову.
  3. Оціни складність за обмеженнями. Python робить ≈10⁷ простих операцій за секунду: n ≤ 100 → підійде майже все; n ≤ 5000 → O(n²); n ≤ 10⁶ → тільки O(n) або O(n log n).

  5. Крайні випадки: n=1, нулі, однакові числа, максимальні значення.

На шляху 1 є a магазинів, на шляху 2 — b, на обох — c. Скільки магазинів усього?

📘 Теорія: множини та формула включень-виключень

  • Шлях 1 і шлях 2 — це дві множини магазинів. Нам потрібен розмір їхнього об’єднання |A ∪ B|.
  • Спільні елементи (перетин |A ∩ B| = c) входять у обидві множини.
  • |A ∪ B| = |A| + |B| − |A ∩ B|. Для трьох множин формула довша: додаємо поодинці, віднімаємо парні перетини, додаємо потрійний.
  • Корисне: так само рахують «скільки учнів люблять А або Б».

Ідея (формула включень-виключень)

Якщо додати a+b, то спільні c магазинів порахуємо двічі. Віднімаємо один раз: a + b − c.

a b c 

a, b, c = map(int, input().split())
print(a + b - c)

🔍 Розбір розв’язку

  1. input().split() розбиває рядок «7 5 3» на список слів, map(int, …) робить їх числами, а розпаковування a, b, c = … роздає по змінних.
  2. Приклад: a=7, b=5, c=3. Тільки перший: 7−3=4, спільні: 3, тільки другий: 5−3=2. Разом 4+3+2=9 = 7+5−3.
  3. Обмеження c ≤ a, b гарантує, що результат не від’ємний. Складність O(1).

3. Хрестики-нулики

📚 Що потрібно знати: рядки, двовимірні масиви, умови, цикли

  • Рядок (str) — це послідовність символів. Нумерація з нуля: s = ".X0" → s[0]=='.', s[1]=='X'. len(s) — довжина, s.count('X') — скільки разів зустрівся символ.
  • Двовимірний масив — таблиця (список списків або список рядків). Поле 3×3: A = [".X.", ".X.", "00."]. Клітинка в рядку i, стовпці j: A[i][j]. Наприклад A[2][0] — це «0».
  • Згортання таблиці в рядок: ''.join(A) склеює рядки в один: «.X..X.00.». Клітинка (i, j) стає позицією i*3 + j. Так порівнювати легше: один цикл замість двох.
  • Цикл for: for i in range(9) проходить i = 0…8.
  • Генератор списку: [i for i in range(9) if A[i] != B[i]] збирає індекси, для яких умова істинна.
  • Умови: if / elif / else; порівняння == != < >; логіка and, or.
  • Умовний вираз: 'X' if k == 0 else '0'.

Чи можна з поля A отримати поле B не більше ніж за один правильний хід?

📘 Теорія: моделювання та рядки

  • Це задача на моделювання: потрібно акуратно перевірити всі умови правил, без хитрих алгоритмів.
  • Правила: X ходить першим, ходи чергуються. Отже, у допустимому полі або X = 0 (наступний ходить X), або X = 0 + 1 (наступний ходить 0).
  • Один хід змінює рівно одну порожню клітинку на символ того, чия черга.
  • Прийом Python: перетворюємо поле 3×3 у рядок з 9 символів (''.join). Тоді порівнюємо клітинки за індексом, а s.count('X') рахує символи.

Ідея — три питання

  1. Скільки клітинок відрізняється? 0 → YES. Більше 1 → NO.
  2. Якщо рівно одна: чи була вона порожньою «.»? Ні → NO (поле змінено).
  3. Чия черга? Якщо хрестиків стільки ж, скільки нуликів — ходить X, інакше — 0. Поставлений символ має збігатися.
Приклад: (клікай по клітинках B, щоб міняти їх!)
A

B

A = ''.join(input() for _ in range(3))
B = ''.join(input() for _ in range(3))
diff = [i for i in range(9) if A[i] != B[i]]
if len(diff) == 0:
    print("YES")
elif len(diff) > 1:
    print("NO")
else:
    i = diff[0]
    turn = 'X' if A.count('X') == A.count('0') else '0'
    print("YES" if A[i] == '.' and B[i] == turn else "NO")

🔍 Розбір розв’язку і приклади

  1. diff — список індексів клітинок, що відрізняються. Його довжина відразу відсікає 0 (YES) і >1 (NO).
  2. turn — чия черга за полем A.
  3. Приклад 1: у A два X і два 0 → ходить X, а в B з’явився 0 → NO.
  4. Приклад 3: у A три X і три 0 → ходить X, додано X → YES (гра не зупиняється при трьох у ряд).
  5. Приклад 4: відрізняються всі 9 клітинок → NO.
  6. Приклад 5: різниці немає → YES.

Типова помилка: забути перевірити, що клітинка була порожньою («.»), і дозволити замінити X на 0.

4. Послідовність

📚 Що потрібно знати: одновимірні масиви, множини, функції, сортування

  • Одновимірний масив — це список: a = [1, 3, 4, 2, 5]. Індекси від 0: a[0]=1, a[-1]=5 (останній). len(a) — довжина, a.append(7) — додати в кінець, max(a) — найбільше.
  • Створення масиву заданого розміру: dp = [1] * n — n одиниць. [0] * (2*m) — 2m нулів.
  • Зчитування масиву: a = list(map(int, input().split())).
  • Вкладені цикли: цикл у циклі. for i in range(n): for j in range(i): перебирає всі пари j < i. Це O(n²): для n = 5·10⁵ занадто повільно.
  • Множина (set) — набір унікальних значень без порядку. set([3,1,3,2]) → {1, 2, 3}. Перевірка x in s працює дуже швидко.
  • Сортування: sorted(s) повертає відсортований список. Так ми отримуємо відсортований список унікальних значень vals = sorted(set(a)).
  • Двійковий пошук — як шукати слово в словнику: дивимось у середину й відкидаємо половину. Це O(log n). У Python його роблять bisect_left(v, x) (позиція першого елемента ≥ x) і bisect_right(v, x) (позиція першого елемента > x) — працюють лише для відсортованого списку.
  • Функція: def f(x): return x + 1. Дозволяє використовувати один код багато разів (наприклад, query).
  • Швидке читання: для великих даних sys.stdin.buffer.read().split() читає все одразу і працює швидше за багато input().
  • Бітові операції: x & 1 — остання цифра двійкового запису (парність), x >> 1 — ділення на 2 нацело.
from bisect import bisect_left, bisect_right
vals = sorted(set([5, 1, 3, 3, 1]))   # [1, 3, 5]
print(bisect_left(vals, 3))            # 1
print(bisect_right(vals, 3))           # 2
print(bisect_right(vals, 4) - bisect_left(vals, 2))   # скільки значень у [2, 4]: 1

Знайти найдовшу підпослідовність, де суми сусідів лежать у [l, r].

📘 Теорія

  • Підпослідовність зберігає порядок, але може пропускати елементи (на відміну від підрядка, де елементи йдуть підряд).
  • Динамічне програмування (ДП): задачу розбивають на підзадачі. Треба визначити (1) стан — що таке dp[i], (2) перехід — як dp[i] виражається через менші, (3) відповідь. Тут стан — «найдовша підпослідовність, що закінчується в i».
  • Складність: n=5·10⁵ → O(n²) це 2,5·10¹¹ дій, неможливо. Треба O(n log n).
  • Стиснення координат: значення до 10¹⁷ замінюємо їхніми номерами у відсортованому списку унікальних чисел.
  • bisect: bisect_left(v, x) — індекс першого елемента ≥ x, bisect_right(v, x) — першого елемента > x. Разом вони дають напіввідкритий діапазон [lo, hi) усіх значень з відрізка [L, R].
  • Дерево відрізків — масив t, де листки лежать у t[m…2m−1], а кожен вузол t[i] зберігає максимум двох дітей t[2i] і t[2i+1]. Оновлення точки: ставимо листок і піднімаємось угору, перераховуючи батьків. Запит [lo, hi): беремо «зайві» вузли на межах і піднімаємось. Обидві дії — O(log n).

Крок 2: швидко (n ≤ 5·10⁵)

Цикл по j повільний — O(n²). Нам треба «максимум dp серед значень a[j] із діапазону [l−x, r−x]». Це запит максимуму на відрізку з оновленням точки — його швидко робить дерево відрізків (O(log n)). Значення до 10¹⁷ → стискаємо координати: індекси у відсортованому списку унікальних значень, межі шукаємо через bisect.

import sys
from bisect import bisect_left, bisect_right
def main():
    d = sys.stdin.buffer.read().split()
    n, l, r = int(d[0]), int(d[1]), int(d[2])
    a = list(map(int, d[3:3 + n]))
    vals = sorted(set(a)); m = len(vals)
    t = [0] * (2 * m)              # дерево максимумів
    def query(lo, hi):             # максимум на [lo, hi)
        res = 0; lo += m; hi += m
        while lo < hi:
            if lo & 1: res = max(res, t[lo]); lo += 1
            if hi & 1: hi -= 1; res = max(res, t[hi])
            lo >>= 1; hi >>= 1
        return res
    best = 0
    for x in a:
        lo = bisect_left(vals, l - x)
        hi = bisect_right(vals, r - x)
        cur = query(lo, hi) + 1    # dp[i]
        p = bisect_left(vals, x) + m
        if cur > t[p]:
            t[p] = cur
            while p > 1:
                p >>= 1
                t[p] = max(t[2 * p], t[2 * p + 1])
        best = max(best, cur)
    print(best)
main()

🔍 Розбір розв’язку

Приклад 1 (l=2, r=6, a = 1 3 4 2 5):

  • a₁=1 → попередніх нема, dp=1.
  • a₂=3 → шукаємо значення з [−1, 3]: підходить 1 (dp=1) → dp=2.
  • a₃=4 → [−2, 2]: підходить 1 → dp=2.
  • a₄=2 → [0, 4]: підходять 1, 3, 4 (dp = 1, 2, 2) → dp=3.
  • a₅=5 → [−3, 1]: підходить 1 → dp=2.
  • Відповідь max = 3 (наприклад, 1, 3, 2).

Що робить код на кожному елементі x: (1) через bisect знаходить діапазон [lo, hi) індексів значень від l−x до r−x; (2) query дає найкращий dp серед них (0, якщо їх немає), тому cur = query + 1; (3) записує cur у листок для значення x і оновлює предків; (4) оновлює відповідь.

Чому достатньо зберігати максимум по значенню: якщо однакове число зустрілось кілька разів, нас цікавить лише найкращий dp серед них, бо їхні сусіди-кандидати збігаються. Приклад 2 (l=r=1, 1 1): сума 1+1=2 ∉ [1,1] → відповідь 1. Складність O(n log n).

Підзадачі за балами: «всі aᵢ однакові» → або 1, або n; n ≤ 5000 → повільне ДП; l=1 → можна спростити; повний бал → дерево відрізків.

📚 Що потрібно знати: множини, графи, черга, масиви-«вказівники»

  • Множина (set): s = set() — порожня. s.add(x) — додати, x in s — чи є (швидко), s = set() знову — очистити.
  • Кортеж (tuple) — пара або трійка значень, що не змінюється: e = (2, 3). Зручно для ребер: u, v = e.
  • Граф — це вершини (точки) і ребра (лінії між ними). У задачі вершини — друзі, ребра — конфлікти. Дві вершини сусідні, якщо між ними є ребро.
  • Як зберігати граф — список суміжності: для кожної вершини список її сусідів. Нумерація вершин з 1, тому розмір n+1:
n = 4
g = [[] for _ in range(n + 1)]   # g[v] — список сусідів v
for u, v in [(1, 2), (2, 3), (3, 1)]:
    g[u].append(v)
    g[v].append(u)               # ребро в обидва боки
print(g[1])                      # [2, 3]
  • Черга (deque) — «хто перший прийшов, той перший пішов». q = deque([s]), q.append(y) додає в кінець, q.popleft() забирає з початку.
  • BFS (пошук у ширину) — обхід графа хвилями: спочатку вершина, потім її сусіди, потім сусіди сусідів. Через нього розфарбовуємо граф у 2 кольори.
  • Дводольний граф — граф, вершини якого можна розфарбувати у 2 кольори (дві команди) так, що кінці кожного ребра різного кольору. Не дводольний тоді, коли є цикл непарної довжини (наприклад, трикутник).
  • DSU (система непересічних множин) — два масиви parent і par. parent[v] — «хто головніший за v у групі». Перехід по parent, поки не дійдемо до кореня, і є find. Масив par[v] зберігає парність: 0 — той самий колір, що й корінь, 1 — інший. ^ — XOR: 0^1=1, 1^1=0.
  • Скидання масивів: щоб не перебирати n елементів, запам’ятовуємо лише ті вершини, яких торкалися (touched), і скидаємо тільки їх.

Розбити послідовність пар-конфліктів на мінімум відрізків, у кожному з яких граф можна розфарбувати у 2 кольори (дві команди).

📘 Теорія

  • Граф — вершини (друзі) і ребра (конфлікти). Дводольний граф — такий, вершини якого можна розфарбувати у 2 кольори так, що кінці кожного ребра мають різні кольори. Це й є «дві команди без конфліктів усередині».
  • Теорема: граф дводольний ⇔ у ньому немає циклу непарної довжини (трикутник — найменший такий цикл).
  • DSU (система неперетинних множин): find(x) повертає «головного» компоненти, union об’єднує компоненти. Зберігаючи для кожної вершини парність шляху до кореня (0 — та сама команда, що й корінь, 1 — інша), ми дізнаємось, чи однакового кольору дві вершини.
  • Жадібний алгоритм: завжди робимо відрізок якомога довшим. Це оптимально, бо якщо підвідрізок дводольний, то будь-який його менший шматок теж, тож подовжувати відрізок ніколи не гірше, ніж обривати.

Ідея

  1. Дві команди ⇔ граф дводольний ⇔ немає циклу непарної довжини.
  2. Жадібність: додаємо ребра по черзі в поточний відрізок, доки він дводольний. Щойно ребро ламає дводольність — починаємо новий відрізок з цього ребра.
  3. Як швидко перевіряти? DSU з парністю: для кожної вершини зберігаємо, чи вона в тій самій команді, що й корінь. Ребро (u,v) ламає граф, якщо u і v в одній компоненті й мають однакову парність.
  4. Новий відрізок: скидаємо лише вершини, яких торкались (а не всі n).
Приклад: 
import sys
def main():
    d = sys.stdin.buffer.read().split()
    n, m = int(d[0]), int(d[1])
    parent = list(range(n + 1)); par = [0] * (n + 1)  # par — парність до кореня
    def find(x):
        path = []
        while parent[x] != x:
            path.append(x); x = parent[x]
        acc = 0
        for v in reversed(path):
            acc ^= par[v]; par[v] = acc; parent[v] = x
        return x
    ans, touched = 1, []
    for i in range(m):
        u, v = int(d[2 + 2 * i]), int(d[3 + 2 * i])
        for _ in range(2):         # пробуємо додати; після скидання — другий раз
            ru, rv = find(u), find(v)
            if ru == rv and par[u] == par[v]:   # непарний цикл
                ans += 1
                for x in touched:
                    parent[x] = x; par[x] = 0
                touched = []
                continue            # додаємо це ребро у новий відрізок
            if ru != rv:
                parent[ru] = rv; par[ru] = par[u] ^ par[v] ^ 1
            touched += (u, v)
            break
    print(ans)
main()

🔍 Розбір розв’язку

  1. Приклад 1: ребра 1-2 і 2-3 → команди {1,3} та {2}. Ребро 1-3 замикає трикутник (непарний цикл) → новий відрізок. Відповідь 2.
  2. par[v] після find — парність v відносно кореня. Це не лише швидкість, а й сама «розфарбовка».
  3. Конфлікт: ru == rv and par[u] == par[v] — u і v вже в одній компоненті й мають однаковий колір, а ребро вимагає різних.
  4. Об’єднання: ставимо parent[ru] = rv і підбираємо par[ru] = par[u] ^ par[v] ^ 1, щоб u і v вийшли різної парності (^ — додавання за модулем 2).
  5. При конфлікті: ans += 1, скидаємо тільки touched (щоб не витрачати O(n) на кожен відрізок) і continue повторює додавання цього ж ребра вже в порожньому відрізку.
  6. Складність майже O(m) (з точністю до коефіцієнта DSU). Для n, m = 10⁶ важливо читати вхід одразу через sys.stdin.buffer.

Типова помилка: скидати весь масив parent на кожному відрізку — це O(n·відрізки) і призводить до ліміту часу.

Рівень 2: перевірка на дві команди

Дано граф. Чи можна розфарбувати його у 2 кольори? (Трикутник 1-2-3 → ні, чотирикутник 1-2-3-4-1 → так.)

from collections import deque
n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v = map(int, input().split())
    g[u].append(v); g[v].append(u)
color = [-1] * (n + 1)
ok = True
for s in range(1, n + 1):
    if color[s] != -1: continue
    color[s] = 0; q = deque([s])
    while q:
        x = q.popleft()
        for y in g[x]:
            if color[y] == -1:
                color[y] = 1 - color[x]; q.append(y)
            elif color[y] == color[x]:
                ok = False
print("YES" if ok else "NO")

Пояснення: фарбуємо першу вершину у 0, її сусідів у 1, їхніх сусідів знову у 0 і так далі. Якщо сусід уже має той самий колір — конфлікт.
